# Atril visual coherence review (Android 2400x1080 + Desktop 2560x1440)

Excluded on purpose: detail saves grouping, gamepad mapping, insertion animation, save watcher scope.
Note: android/23 and android/24 are the same file (scrolled Library, not the detail screen); desktop/01 and 03 are also the same.

## P0: looks broken
1. **Android scroll content cut off by a dead band.** android/10–15, 17, 22, 23, 30: lists stop with a hard edge at y≈910–955. Below that is a ~100px empty black band above the gesture bar, and the rail also ends at y≈1015. Fix: pass `WindowInsets.navigationBars` as the LazyColumn/grid `contentPadding` instead of padding the container, and let the rail and content fill to the bottom edge.
2. **Desktop icons missing (blank rounded rectangles).** desktop/10–16, 20, 30: the rail logo "Atril", the "Biblioteca" rail item, the section icons for Launcher/Sistema/Controles/Acerca de, the random button in the Library toolbar (white square at x≈2302) and the missing-cover placeholder all show a blank rectangle. Fix: map these to real Material icons (VideogameAsset/GridView, Casino, Info, Settings) the same way Android does.
3. **Desktop type and controls far too small for 1440p.** desktop/all: body text is ~12px, page titles ~20px, chips are ~30px tall, and content fills only the top third of the window. The Android equivalent reads about 2x larger. Fix: apply a density factor on desktop (for example `LocalDensity` scaled ×1.5 when height ≥1400, or honour GDK_SCALE), and cap Settings content width at ~1200dp.

## P1: hierarchy and consistency
4. **Play menu differs between platforms and from the rail.** android/02 uses a full-height drawer with Play/Library/Sync/Settings. desktop/02 uses a tiny unstyled dropdown with no scrim and no current item ("Biblioteca, Saves, Ajustes, Plataformas, Descargas") that covers the "Todas" chip. The About tab claims "same overlay on every tab", but the other tabs show a rail. Fix: reuse the drawer composable on desktop with the same 4 items, the highlight and a scrim, and correct the About text.
5. **Page header not shared across screens.** The serif title sits in a different place on each screen: Play (android/01, large, with hamburger), Settings (y≈160), Download queue (y≈208, back arrow, android/31), and Library has no title at all on Android (android/20) while desktop has "Biblioteca". Fix: one `PageHeader(title, navIcon?, actions)` with a fixed height and baseline, used on every tab.
6. **Selected state uses three colours.** Selected Settings tabs are a green fill, Library filter "All" is an amber fill (android/20), the desktop Play chip "Todas" is amber, and the selected rail item is brown on Android but green on desktop. Fix: one selected token for chips and rail (amber/primaryContainer) on both platforms.
7. **Primary button roles mixed.** "Open Library", "Select folder" and "Refresh" are green, while "Sync now", "Conectar con QR", "Guardar" and "Escanear ahora" are amber. "Gestionar plataformas" and "Comprobar cambios" are green, and "Seleccionar carpeta" is outlined. Fix: amber filled = the one primary action per card, green tonal = secondary, outlined = tertiary. Do not stretch buttons to full width ("Select folder" android/12, "Sync now" android/30, "Sincronizar ahora" desktop/30 at 2450px).
8. **Library staggered grid.** android/22–23: Lucienne's Quest is twice as tall as its row, leaving large holes, and Wolfenstein ends up alone after scrolling. Desktop (desktop/20) uses a uniform grid. Fix: fixed 3:4 cell with `ContentScale.Crop` (or Fit plus letterbox) on Android to match desktop.
9. **Card text overlay has no scrim and the download button is too big.** android/22 ("Space Hulk", "Escape from…") and desktop/20 ("Baal", "Barbarian II"): titles sit on busy art. On Android the round download button covers about 1/3 of the card width and the cover logo. Fix: bottom gradient scrim (transparent→70% black) under the title and size, and shrink the download badge to ~32dp at 60% opacity.
10. **Download queue card breaks the gutter.** android/31: the empty card starts flush against the rail (x=210) and runs past the right edge. Every other screen uses a ~42px gutter (252…2358). Fix: same horizontal padding as Settings.
11. **Desktop Play info panel collides with the next cartridge.** desktop/01: the N64 cart is clipped at x≈1530 and the title and buttons start at x=1536, on top of it. The badge "2" sits next to "+" instead of on the downloads button. Fix: put the info column in its own lane after the focused card plus a gap (or dim/blur the neighbouring card behind it), and anchor the badge to the download icon.
12. **Same icon for Play and Library in the Android rail** (android/10–31: both gamepad). The rail label is "Sync" on Android and "Saves" on desktop, and the brand is the "ATRIL" wordmark on Android but a round avatar on desktop. Fix: Play = PlayArrow (as desktop), Library = GridView/VideoLibrary, one label, and the wordmark on both.
13. **Settings sections differ between platforms.** Appearance: Android has no Theme section and its toggle is "Show physical media by default", while desktop has Tema/Idioma and a different toggle (android/11 vs desktop/11). Downloads: section order is reversed (android/14 vs desktop/14). About: Android starts with Controls, desktop starts with Updates. Fix: align section order and names. Platform-only items go last.
14. **Desktop section icons are generic.** desktop/10–12: Servidor RomM, Plataformas, Tema, Idioma and Escanear all use the same list icon. Android uses specific ones. Fix: Dns, Palette, Language, Search, etc.
15. **Desktop Saves screen does not use cards.** desktop/30: only the status is in a card. "Cambios pendientes" and "Sincronización automática" are loose text, and "Off" is not translated. Fix: wrap them in the same SectionCard as Settings and translate "Off".
16. **Desktop slider reads as a progress bar.** desktop/14: the inactive track is dark green with dots and spans 2400px. Fix: inactive track = surfaceVariant/outline, and limit the slider width to ~480dp.

## P2: polish
17. Android Library empty state (android/20) is plain text only, while Play, Sync and Queue use icon + title + CTA. Fix: reuse the EmptyState composable with a "Select platform" button.
18. Badge colours: the red/pink "8" badge on the green FAB (android/22) is off-palette and its check-download icon is unclear. Desktop uses an amber badge. Fix: amber badge plus a standard Download icon.
19. Toggle-row titles (android/11, 13–15) use regular weight with wide letter-spacing and look like a different font from the section headers. Fix: `titleMedium`.
20. android/02 drawer: the "ATRIL" eyebrow plus the "Atril" title is redundant, and the "ATRIL Play" header shows through faintly behind it. Fix: opaque drawer surface and drop one of the two labels.
21. android/17: the "None" action with a crossed-grid icon reads like a status, not an action. Fix: text button "Hide all".
22. desktop/20: the toolbar mixes four button styles (outlined dropdown, bare icons, outlined "Subir juego", tonal "Descargar faltantes"). Sizes show "0 KB" (Abu Simbel, Double Dragon). Missing covers show an empty box. Fix: one button style per row, hide unknown sizes, use a platform-initials placeholder as in android/17.
23. Android Library toolbar download/upload icons have no labels or tooltips. Desktop uses the text "Subir juego". Fix: add contentDescription/tooltip and use the same wording on both platforms.
